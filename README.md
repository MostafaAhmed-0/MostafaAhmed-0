## 👋 About Me

I'm **Mostafa Ahmed**, a Computer Science graduate from Ain Shams University, based in Cairo, Egypt. I build cross-platform applications with **Flutter and Dart**, focusing on maintainable code, responsive interfaces, and practical user experiences.

Alongside development, I have experience teaching programming and Flutter, helping learners understand concepts and build projects step by step. I'm also expanding my backend knowledge and exploring how mobile applications connect to reliable backend services.

- 📱 Focused on Flutter and cross-platform mobile development
- 🧱 Interested in Clean Architecture, feature-first structure, and state management
- 🔌 Experienced with REST APIs, Firebase, and Supabase
- 👨‍🏫 Flutter instructor with hands-on teaching experience
- 🌱 Currently growing my skills in backend development with Go
- 📍 Cairo, Egypt
